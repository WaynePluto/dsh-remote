## 维护规则

- 只描述当前行为和明确的待办，不保留已取消方案、旧功能或调试过程。
- 插件功能与使用说明放在各插件根目录 README，本目录只保留索引、共用规则和源码依据。
- 路线图不重复记录实现细节；完成一项立即更新状态，实机未验收的项目保持未勾选。
- `docs` 内每个文件最多 600 行，按主题拆分而非按固定行数截断。
- 移动文档时同步更新链接及引用章节；源码路径相对对应仓库根，dsh 根路径只记在 `dsh-source` skill。
