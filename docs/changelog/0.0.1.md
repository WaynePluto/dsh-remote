# 0.0.1（2026-09-15）

首个发布：通过浏览器远程指挥 dsh。在电脑上让 dsh 干活，出门掏出手机接着指挥，
回家换笔记本打开还是同一个会话。

## 核心能力

- **自带 dsh**：dsh 作为依赖随包携带（内嵌版本 0.1.5-rc.2），不需要单独安装 dsh，
  升级 dsh 就是升级 dsh-station；不改 dsh、不 fork，始终跟官方版本
- **反向隧道**：被开放的机器主动拨向入口机器，不需要公网 IP、路由器不用做端口映射；
  dsh 永远只监听 `127.0.0.1`，对外的门全由控制台把守
- **必须登录**：所有非本机浏览器访问都要「密码 + TOTP 动态码」，
  仅本机 loopback 访问免登录
- **任意一台都能当入口**：每台机器跑自己的 dsh + 控制台（relay）+ 拨号器（connector），
  挂上来的机器各分一个固定端口，可以直接存书签
- **公网域名模式**：入口机器配置泛域名后，每台机器有自己的
  `https://<机器>.<域名>` 地址（Caddy/nginx 终结 TLS），一次 DNS 配置新增机器不再加记录
- **远程入口自动生效**：在本机「远程入口」页粘完入口机器给的命令后，connector 自动连上，
  dsh 自动重启以信任新的地址（无需重启整个程序），页面实时显示重启进度与失败原因

## 安装与运行

- 三平台绿色包：Windows x64（托盘程序 `dsh-station.exe` + `start.ps1`）、
  Linux x64、macOS arm64（`start.sh`），解压即用
- 零原生模块、无需编译工具链，只要 Node.js 22.19+
- Windows 托盘：打开 dsh 界面 / 管理界面、启动停止重启、查看日志、开机自启
- 首次设置走浏览器向导（仅本机开放）；无头服务器用 relay 救急命令
  `init` / `passwd` / `totp reset`
- 服务器 7×24 部署：`deploy/` 提供个人用户 systemd unit 与 Caddyfile 模板

## 内置 dsh 扩展

只加载到专属的 `dsh-station-web` profile，不改官方配置、不实现第二套插件管理：

- **设置与模型**：全局提示词编辑、出网代理、GitHub Copilot 设备码登录、
  models.dev 模型目录、模型能力与协议覆盖、常用模型收藏、任务完成通知
- **会话与工作区**：失败重试、会话滚动导航、用户消息分叉、
  工具状态、技能状态、文件浏览（文件树 + Git 状态）、常驻服务、交互终端
- **运行环境**：精简模式预设、远程完整设置页、浏览器内目录选择、固定 YOLO、
  旧 WebKit 浏览器兼容垫片与诊断页

## 已知限制

- Windows 托盘程序未签名，SmartScreen 会提示「未知发布者」
- 控制台自身不做 TLS，公网部署需要 Caddy / nginx 等反代终结
