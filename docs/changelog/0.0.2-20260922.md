# 0.0.2-20260922（2026-09-22）

预发布版本：内置插件全部转为可停用、内嵌 dsh 升级到 0.1.6-alpha.2，附带一轮界面改进。
版本号带日期后缀，GitHub Release 会标记为预发布。

## 内置插件全部可停用

- 22 个内置 dsh 扩展从硬编码装载改为「默认受管 Profile Bundle」：现在可以在 dsh 的
  插件页看到并停用它们，停用后重启不会被自动补回
- 托盘菜单为每个被停用的受管项生成独立的「补回×××」菜单，选择后自动重启补回；
  命令行 `dsh-remote --restore-bundle <包名>` 同样可用
- remote-privileged 拆分：隧道连接所需的注入仍是不可停用的壳级补丁；
  原「远程完整设置页」独立为 remote-settings 插件（可停用）
- 插件装载顺序由 launcher 的权威清单固定：出网代理先于依赖网络的插件、固定 YOLO 末位

## 升级 dsh 0.1.6-alpha.2

- 内嵌 dsh 从 0.1.5-rc.2 升级到 0.1.6-alpha.2（上游 alpha 版本）
- 适配上游接口变化：常用模型收藏、用户消息分叉、子代理深度、文件侧栏入口、
  旧 WebKit 浏览器兼容
- 术语统一：用户文案「精简模式」改为「简洁模式」，与预设界面一致

## 界面与体验

- services 日志弹窗与 turn-retry 失败详情弹窗支持全屏切换，全屏时隐藏拖动与调整手柄
- services 常驻服务列表单行省略，长服务名不再把行尾按钮挤换行
- Windows 托盘：双击启动在 dsh 就绪后弹「已启动」系统通知；
  开机自启动改为静默登录，旧自启条目自动升级

## 已知限制

- 内嵌 dsh 为上游 0.1.6-alpha.2，API 仍可能变化
- 部分插件功能待实机验收（详见仓库 roadmap）
