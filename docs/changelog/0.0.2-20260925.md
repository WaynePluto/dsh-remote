# 0.0.2-20260925（2026-09-25）

预发布版本，0.0.2 系列的第二次迭代。版本号带日期后缀，GitHub Release 会标记为预发布。

## 发行介质收敛为四个发布端

- Windows / macOS / Linux 桌面版 + Linux 服务版 zip，共四个发布端；win/mac 不再提供
  绿色包（服务版 zip）
- 每个介质分**轻量版（lite）/ 完整版（full）**；桌面版再分 **setup（安装包）**与
  **portable（便携 zip）**两种形态：Windows 是 NSIS `setup.exe`，macOS 是 DMG
  （拖入 Applications），Linux 是 deb
- 轻量版（lite）与服务版**不内置 Node.js**，要求系统 Node ≥ 22.19.0；桌面完整版（full）
  随包附带固定版本 Node（官方 SHA-256 校验），装好即用
- Linux 服务版 zip 文件名带 `server` 标记（`…-linux-x64-server-<变体>.zip`），始终用系统 Node
- 发布命令按平台 × 变体拆分：`release`（本机全部）与 `release:win|mac|linux:lite|full`
  （`release:linux:<变体>` 同时产出服务版 zip）；推 tag 后由 CI 三个原生 runner 构建全部介质

## 桌面版（DSH 工作站）

- Wails v2 桌面应用：独立模式托管自有后台（dsh + relay + connector），双击即用；
  另有 attach 开发模式附着开发栈
- 自绘标题栏、托盘（后台启停与壳自重启恢复）、桌面通知点击定位会话、应用图标统一
- Windows 实机验收通过（隔离数据 + 随包 Node、强制杀壳后 4 秒回收全部后台子进程、
  单实例互斥）；macOS/Linux 桌面版由 CI 原生 runner 构建，实机验收进行中
- 首次免设置：本机打开即是 dsh 工作台，无需先创建管理员；远程能力在管理界面按需开启

## 更名 dsh-station（DSH 工作站）

- 包名、dsh profile（`dsh-station-web`）、数据目录（`~/.dsh-station`）与用户文案统一改名
- 不做旧 dsh-remote 数据目录/配置的运行时迁移（一次性改名，历史数据手动搬移）；
  relay.db 迁移合并为单一 CREATE，schema 版本号归一为 1

## 升级 dsh 0.1.7-rc.1

- 内嵌 dsh 从 0.1.6-alpha.2 升级到 0.1.7-rc.1，适配 settings 与预设新契约
- 25 个插件包补充显示元数据（中英文 locale）；launcher 检测 dsh Bundle 静默跳过
  诊断并响亮警告

## 其他

- 插件分发与生命周期完善：配套升级保留停用状态、卸载不自动补回、安装介质同盘缓存
  与 pnpm 主版本迁移
- 开发栈使用独立 home（`~/.dsh-station-dev`）与错开端口，可与发行版实例并行运行

## 已知限制

- 内嵌 dsh 为上游 0.1.7-rc.1（developer preview，仍可能有破坏性变更）
- 桌面版原生网络/权限隔离（S1.3）未实现，未通过安全验收前不得宣传为安全发行版
- macOS/Linux 桌面版与部分插件功能待实机验收（详见仓库 roadmap）
