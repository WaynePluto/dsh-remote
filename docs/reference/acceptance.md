# 联调验收

本清单用于当前实现，不保存旧版本结果。未执行的项目不能因自动测试通过而勾选。
总进度见 [路线图](../05-roadmap.md)。测试产生的凭据与日志留在忽略目录，不提交。

## 准备

在仓库根执行：

```powershell
pnpm install
pnpm build
pnpm dev
```

访问日志打印的 loopback 控制台，首次使用时设置管理员密码、绑定 TOTP。
密码至少 6 字符且四类字符中至少三类。源码开发可使用 pnpm relay:init、relay:passwd 和 relay:totp-reset。
插件构建后必须重启 dsh；仅刷新页面不能更新产物。

手机与电脑连接同一局域网，并按需要由操作者设置防火墙入站规则。
dsh 始终绑定 127.0.0.1，手机访问 relay，不能直接暴露 dsh。
HTTP 局域网模式为高风险开发配置，密码和 cookie 可能被监听，用完关闭。
命令行排查 loopback/LAN HTTP 时，Invoke-WebRequest 使用 -NoProxy，避免代理拦截造成误判。

## 浏览器与认证

- [ ] loopback socket + loopback Host 访问控制台可免登录。
- [ ] 局域网 IP 访问必须先登录；不能进入首次设置表单抢注管理员。
- [ ] 错误密码或验证码被拒，正确密码与 TOTP 登录成功并返回原页面。
- [ ] 在独立测试环境验证 5 次失败后限流，避免锁住日常账号。
- [ ] HTTP 测试 cookie 为 host-only、HttpOnly；HTTPS 为 Secure + __Secure-，域名共享范围正确。
- [ ] 登出撤销会话，改密码/TOTP 后既有会话失效。
- [ ] HTTP、API 与 WebSocket 都执行 Host/Origin 与 cross-site 校验。
- [ ] dsh 首页自动交换 cookie，API 401 不被改成循环重定向。
