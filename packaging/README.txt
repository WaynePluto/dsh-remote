================================================================================
  dsh-remote —— 用手机 / 异地电脑通过浏览器远程指挥这台机器上的 dsh
================================================================================

解压后目录里应该有这些东西（启动文件按平台只有对应的那一组）：

  【Windows 包】
  dsh-remote.exe                   Windows 启动程序，双击它就行（常驻通知区域）
  start.ps1                      Windows 的另一条路：PowerShell 7 脚本

  【Linux / macOS 包】
  start.sh                       Linux / macOS 启动脚本

  【三个平台都有】
  README.txt                     本文件
  dsh-remote.config.example.json   配置示例（不改也能用）
  dist/                          程序本体
  node_modules/                  依赖，含随包携带的 dsh

【注意】包是分平台的，文件名里写了平台（如 dsh-remote-0.0.1-win-x64.zip）。
        node_modules 里有只对应当前平台的二进制，拿到别的平台上是跑不了的。


--------------------------------------------------------------------------------
1. 先装 Node.js
--------------------------------------------------------------------------------

这个包不自带 Node，用的是你机器上的 Node。

  要求版本：22.19.0 或更高
  下载地址：https://nodejs.org  （下 LTS 就行）

检查方法：打开终端敲 node -v，显示 v22.19.0 或更高即可；
提示「找不到命令 / 不是内部或外部命令」就是还没装。


--------------------------------------------------------------------------------
2. 启动（Windows）
--------------------------------------------------------------------------------

把压缩包整个解压出来，然后双击目录里的 dsh-remote.exe。就这两步。

双击之后不会出现黑窗口。dsh-remote.exe 会在任务栏右下角的通知区域（托盘）放一个
图标，dsh、控制台、隧道连接器三个进程都跑在它下面。图标一开始可能被折叠在「^」
里，点开「^」能看到，也可以把它拖出来常驻显示。

在这个图标上点右键，菜单是：

  打开 dsh 界面      用默认浏览器打开 http://127.0.0.1:30809
                     （双击图标是同一件事）
  打开管理界面       用默认浏览器打开 http://127.0.0.1:30809/_admin
  ────────
  启动 / 停止 / 重启  管上面那三个进程；当前做不了的那几项是灰的
  ────────
  查看日志           打开日志文件，见下面「日志在哪」
  开机自启动         打勾表示已经加进当前用户的开机启动项
  ────────
  退出               先把三个进程干净地停掉，再收起图标退出

改密码、重置验证器（TOTP）、加机器、踢机器，全都在浏览器的管理界面里做，所以菜单
里没有这几项，也不用敲命令 —— 从「打开管理界面」进去就是。

「打开 dsh 界面」和「打开管理界面」都经过本机中转（relay），它会替你完成 dsh 的
登录交换；不要按 dsh 的真实端口（默认 3080）直连，没有这次交换，浏览器只会看到
一句 dsh web authentication required。

第一次运行还没有管理员账号时，图标会弹一条通知提醒你去设置，点那条通知就会打开
设置页。除此之外本程序不会自己打开浏览器，地址都要你自己点。

改过 dsh-remote.config.json 里的端口的话，菜单里那两项会按你配的端口走。

日志在哪：托盘模式没有控制台，原本打印在窗口里的东西全部写进

    <home>\dsh-remote.log       home 默认是 C:\Users\你的用户名\.dsh-remote

它涨到 2 MB 就会自动改名成 dsh-remote.log.1 再重开一个，最多占 4 MB，不会一直长。
菜单里的「查看日志」打开的就是这个文件。

没装 Node.js 的话，双击时会弹一个对话框告诉你去 https://nodejs.org 装，不会一
声不响地什么都不发生。

【SmartScreen】第一次运行时 Windows 可能弹出蓝色的「Windows 已保护你的电脑」，
        提示发行者不受信任。这是因为这个 exe 没有做代码签名（证书要按年付费），
        并不代表它有问题。点窗口里的「更多信息」，再点「仍要运行」即可。
        实在不放心就改用下面的 start.ps1，两条路做的事情完全一样。

另一条路：start.ps1

如果你更习惯在终端里跑、想实时看到三个进程的输出，或者机器上本来就装了
PowerShell 7，可以用 start.ps1。它在终端里前台运行，按 Ctrl+C 结束。
它需要 PowerShell 7；系统自带的是 Windows PowerShell 5.1，不是同一个东西，
没有的话得到 https://aka.ms/powershell 装一个 —— 这也正是本包额外准备一个
dsh-remote.exe 的原因。

【注意】start.ps1 不能双击运行。双击 .ps1 是用记事本打开它，不是执行它。
        Windows 对 .ps1 的默认设定就是这样，这不是本包的问题。

用法（任选其一）：

  A. 在文件上点右键 → 「使用 PowerShell 运行」

  B. 在这个目录里打开终端（地址栏敲 pwsh 回车，或右键「在终端中打开」），执行：

         pwsh -File .\start.ps1

如果提示「无法加载文件 ... 未对文件进行数字签名 / 因为在此系统上禁止运行脚本」，
说明脚本被「网络下载文件」标记（Mark of the Web）或执行策略挡住了。在同一个目录
下的 PowerShell 7 里执行这一行解除标记：

    Unblock-File .\start.ps1

还不行的话，用下面这条命令启动，它只对这一次调用放宽策略，不改系统设置：

    pwsh -ExecutionPolicy Bypass -File .\start.ps1


--------------------------------------------------------------------------------
3. 启动（Linux / macOS）
--------------------------------------------------------------------------------

    chmod +x ./start.sh      # 只有在提示 Permission denied 时才需要
    ./start.sh

也可以直接： sh ./start.sh


--------------------------------------------------------------------------------
4. 第一次启动要做什么
--------------------------------------------------------------------------------

第一次启动时还没有管理员账号，管理界面暂时不能登录。

双击 dsh-remote.exe 启动的话，托盘图标会弹一条「还没有设置完成」的通知，点它就会
打开设置页；用 start.ps1 / start.sh 启动的话，终端里会打印同一个地址，形如：

    http://127.0.0.1:30809

请在【运行这个包的这台机器上】用浏览器打开它，然后：

  1. 填账号名（默认 admin，可以改成别的，只能用字母、数字和 . _ -）并设一个管理员密码
     （至少 6 个字符，且用上大写字母、小写字母、数字、符号里的至少 3 类）
  2. 用手机上的验证器 App 扫页面上的二维码
     （Microsoft Authenticator、Google Authenticator、1Password 都行）
  3. 输入 App 里的 6 位动态码确认

以后从别的设备登录，要输入的就是这个账号名 + 密码 + 动态码。忘了账号名的话，在
这台机器上打开管理页的「账号」页就能看到。

设置向导只对本机 127.0.0.1 开放。同一个局域网里的其他人访问时只会看到一句
「请到那台机器上完成设置」，抢注不了管理员。

设好之后，日志（或终端）里会写出全部访问地址：本机免登录，局域网需要密码 + 动态码。
之后要加第二台机器、踢掉机器、改密码、重置验证器，全都在浏览器的管理页 /_admin
里做，不用再敲命令。管理页顶部一行 tab 就是它的全部三个页面：

    /_admin            机器      别的机器挂在本机上、签发注册令牌
    /_admin/hub        远程入口  本机挂在谁身上，设置 / 取消
    /_admin/account    账号      改密码、重置验证器

登录、机器挂上来、机器被停止移除、改密码这些安全记录没有页面，它们写在
上面那份日志里（带 "audit":true 的 JSON 行），同时落在 home 目录的 relay.db 里。

要停止：托盘图标上点右键 →「退出」；用 start.ps1 / start.sh 启动的就在终端里按
Ctrl+C。两种方式都会让 dsh、控制台、隧道连接器三个进程一起干净地退出，不留后台
进程占着端口。

如果这台机器没有图形界面（比如云服务器），浏览器打不开 127.0.0.1，
就用这条命令在终端里创建管理员：

    node dist/relay.js init


--------------------------------------------------------------------------------
5. 配置文件（可选，不改也能跑）
--------------------------------------------------------------------------------

把 dsh-remote.config.example.json 复制成 dsh-remote.config.json 再改。
文件必须和 dsh-remote.exe / start.ps1 / start.sh 放在同一个目录里。JSON 里写不了注释，所以字段说明放在这儿：

  dsh.port        本机 dsh 监听的端口，默认 3080。
                  它永远只监听 127.0.0.1，外面进不来。
  relay.port      控制台 / 中转服务的端口，默认 30809。你的浏览器访问的就是它。
  relay.host      控制台绑定的地址，默认 0.0.0.0（局域网可访问，但必须登录）。
                  只想自己本机用就改成 127.0.0.1。
  relay.slug      这台机器在控制台上的名字，只能用小写字母、数字和连字符。
                  删掉这一行就用本机的计算机名。
  home            存放本机身份与数据库的目录，默认 ~/.dsh-remote。
                  托盘模式的日志文件 dsh-remote.log 也放在这里。

还有几个一般用不到的字段，需要时再加：

  dsh.profile     dsh 的 profile 名，默认 dsh-remote-web。别改，除非你清楚后果。
  dsh.extraArgs   透传给 dsh 的额外命令行参数，字符串数组，默认 []。
  relay.data      SQLite 数据库路径，默认是 home 目录下的 relay.db。

写错了不会被悄悄忽略：启动时会直接报错并指出是哪一项。托盘模式下这条报错在日志
文件里（右键菜单 →「查看日志」）。


--------------------------------------------------------------------------------
6. 安全须知
--------------------------------------------------------------------------------

【重要】不要在没有 HTTPS 的情况下把它暴露到公网 —— 局域网内用 HTTP 是权衡后可
接受的（启动时会打印高危警告），放到公网则必须在前面套一层 HTTPS（例如用 Caddy
自动申请证书）。dsh 自己没有任何认证，所有的门都在控制台这一层。

更多说明见项目仓库的 README.md 与 docs/04-security.md。
