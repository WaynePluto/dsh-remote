DSH 工作站（dsh-station）桌面版
================================================================================

这是官方 DeepSeek Harness (dsh) 的桌面封装：双击桌面应用即可使用，
dsh 由本应用托管启动，不需要预装 dsh 或 Node（轻量版需要系统 Node）。

【快速开始】
  1. 启动本应用（安装版从开始菜单/应用目录启动）。
  2. 窗口先显示启动进度，本机入口就绪后自动进入 dsh 界面。
  3. 首次使用无需注册任何账号：本机页面直接可用。
     只有使用远程能力（打开「管理控制台」）时，才会引导创建管理员账号与动态码。
  4. 通知区域托盘图标：显示窗口、在浏览器中打开、启动/停止/重启后台、退出。
     关闭窗口只隐藏到托盘，后台继续运行；托盘「退出」才真正停止全部进程。

【轻量版 / 完整版】
  - 完整版（full）附带固定版本 Node 与 Office 文档预览引擎，开箱即用。
  - 轻量版（lite）需要系统已安装 Node.js ≥ 22.19.0；不带 Office 预览引擎，
    打开 Office 文档预览会提示转换不可用。
  - 两者是同一个程序，只有随包内容不同。

【目录说明】
  dsh-station(.exe)              桌面应用本体
  package/                       dsh、插件与后台服务（launcher/relay/connector）
  runtime/node/                  随包 Node（仅完整版）
  plugins/                       第三方插件安装介质（在 package/ 内）
  用户数据保存在 ~/.dsh-station 与 ~/.dsh（标准 DSH_HOME），
  卸载或删除本目录不会影响会话、账号与机器关系。

【注意】
  - 本应用把 dsh 绑定在 127.0.0.1，远程访问经带认证的入口转发；
    所有非本机浏览器访问必须登录。
  - 远程能力（从其他设备访问本机）在「管理控制台」配置。
  - 未签名的安装包可能触发系统安全提示，属于正常现象。
